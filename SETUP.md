# Installation

1. On GitHub, open or create the public profile repository **kailash105/kailash105** (repository name must match username).
2. Copy `README.md` and the `assets` directory to the **root** of that repository.
3. Commit changes and open https://github.com/kailash105.
4. Review each linked project and any personal details before publishing.

## Design notes
- `assets/hero.svg` is an SVG image with simple animation, no JavaScript needed. It can be customized in a text editor.
- Expand/collapse interactions use native GitHub `<details>` elements.
- Repo statistics use third-party SVG widgets and may occasionally fail under provider outages or rate limits.
- GitHub README HTML is sanitized: custom JS and CSS apps are not supported.
- This profile intentionally avoids hard-coded public activity counts that become stale.
- If you want a contribution snake, it needs a GitHub Actions workflow and an output branch. This version does not depend on one.
